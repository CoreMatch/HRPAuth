# 配置结构

首次启动项目时，若根目录无 `config.yaml` 则会自动生成一份默认配置。

> 详细实现： [`config/config.go`](../../config/config.go) · [`controllers/startup_controller.go`](../../controllers/startup_controller.go)

## 完整 `config.yaml` 示例

```yaml
version: "2"
site:
  name: "HRPAuth"
  implementation: "HRPAuth"
  version: "1.0.0"
server:
  port: ":8080"
  cors_origin: "*"
database:
  host: "localhost"
  db_name: "hrpauth"
  user: "root"
  password: ""
  charset: "utf8mb4"
redis:
  host: "localhost"
  port: 6379
  password: ""
  db: 0
smtp:
  host: "smtp.example.com"
  port: 587
  username: ""
  password: ""
  encryption: "tls"
  from_email: "noreply@example.com"
  from_name: "HRPAuth"
manage:
  token: "<auto-generated on first startup>"
security:
  password_cost: 10              # bcrypt cost for HRPAuth user passwords
  rate_limit_max_attempts: 10    # 登录失败计数上限
  rate_limit_window_sec: 600     # 登录失败计数窗口（秒）
  enable_captcha: true           # 是否开启图形验证码（开启后 /register 强制校验）
  captcha_ttl: 300               # 图形验证码有效期（秒），存于 Redis
yggdrasil:
  server:
    name: "My Server"
    implementation: "HRPAuth"
    version: "1.0.0"
    skin_domains:
      - "example.com"
  security:
    token_expiry_days: 15        # accessToken 有效期（天）
    session_expiry_seconds: 3600 # 刷新令牌/会话有效期（秒）
    max_texture_width: 1024      # 材质最大宽度（px）
    max_texture_height: 1024     # 材质最大高度（px）
  feature_flags:
    non_email_login: false
    legacy_skin_api: false
    no_mojang_namespace: false
    enable_mojang_anti_features: false
    enable_profile_key: false
    username_check: true
```

## 字段说明

### 顶层

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | string | 配置 schema 版本（当前 `"2"`） |

### `site` — 站点信息

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `site.name` | string | `"HRPAuth"` | 服务名，出现在 `GET /status` 与 Yggdrasil `meta.serverName` |
| `site.implementation` | string | `"HRPAuth"` | 实现名 |
| `site.version` | string | `"1.0.0"` | 实现版本号 |

### `server` — HTTP 服务

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `server.port` | string | `":8080"` | 监听端口（需带冒号） |
| `server.cors_origin` | string | `"*"` | CORS 允许的 Origin，`"*"` 表示全部 |

### `database` — MySQL

| 字段 | 类型 | 说明 |
|------|------|------|
| `database.host` | string | 主机地址 |
| `database.db_name` | string | 数据库名 |
| `database.user` | string | 用户名 |
| `database.password` | string | 密码 |
| `database.charset` | string | 字符集，推荐 `utf8mb4` |

### `redis` — Redis

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `redis.host` | string | `"localhost"` | 主机 |
| `redis.port` | int | `6379` | 端口 |
| `redis.password` | string | `""` | 密码（无密码留空） |
| `redis.db` | int | `0` | 数据库编号 |

### `smtp` — 邮件

| 字段 | 类型 | 说明 |
|------|------|------|
| `smtp.host` | string | SMTP 服务器 |
| `smtp.port` | int | SMTP 端口 |
| `smtp.username` | string | SMTP 用户名 |
| `smtp.password` | string | SMTP 密码 |
| `smtp.encryption` | string | `"tls"` / `"starttls"` / `"none"` |
| `smtp.from_email` | string | 发件人邮箱 |
| `smtp.from_name` | string | 发件人显示名 |

### `security` — HRPAuth 业务层（**注意：在顶层，不在 yggdrasil 下**）

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `security.password_cost` | int | `10` | bcrypt cost。值越大越安全但越慢 |
| `security.rate_limit_max_attempts` | int | `10` | 登录失败计数上限 |
| `security.rate_limit_window_sec` | int | `600` | 登录失败计数窗口（秒） |
| `security.enable_captcha` | bool | `true` | **是否开启图形验证码**（开启后 `/register` 强制校验） |
| `security.captcha_ttl` | int | `300` | 图形验证码在 Redis 中的有效期（秒） |

> ⚠️ **历史迁移提醒**：早期版本的 `enable_captcha` 与 `captcha_ttl` 位于 `yggdrasil.security.*` 下。**现已迁移到顶层 `security.*`**，旧路径不再生效。如使用老配置文件，请手动迁移这两个字段。

### `manage` — 运维 Manage Token（M-T）

| 字段 | 类型 | 说明 |
|------|------|------|
| `manage.token` | string | **Manage Token（M-T）**，首次启动时由 `utils.GenerateRandomToken(32)` 随机生成并写入 `config.yaml` |

**M-T 的用途**：作为"超级 remtoken"，在所有以 Remember Token 鉴权（`remember_token` / `remtoken` / `rt` 字段）的站点端点上等价于目标用户的 remember_token，但需要通过 `uid` 或 `email` 显式指定目标用户。

典型使用场景（举例）：

```bash
# 用 M-T 查询任意用户的资料
curl -X POST https://auth.example.com/user \
  -H "Content-Type: application/json" \
  -d '{"remember_token":"<M-T>","uid":"42"}'

# 用 M-T 为任意用户开启 TOTP
curl -X POST https://auth.example.com/totp/setup \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","remtoken":"<M-T>"}'

# 用 M-T 重置任意用户名
curl -X POST https://auth.example.com/change-username \
  -H "Content-Type: application/json" \
  -d '{"remember_token":"<M-T>","uid":"42","username":"NewName"}'
```

> ⚠️ **安全提示**：M-T 等价于最高权限操作者，**请勿外泄**。轮换 M-T 需编辑 `config.yaml` 中的 `manage.token` 字段并重启服务。

### `yggdrasil.server` — Yggdrasil 元信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `yggdrasil.server.name` | string | Yggdrasil `meta.serverName` |
| `yggdrasil.server.implementation` | string | Yggdrasil `meta.implementationName` |
| `yggdrasil.server.version` | string | Yggdrasil `meta.implementationVersion` |
| `yggdrasil.server.skin_domains` | array | 允许的 skin domain 列表 |

### `yggdrasil.security` — Yggdrasil 协议层

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `yggdrasil.security.token_expiry_days` | int | `15` | accessToken 有效期（天） |
| `yggdrasil.security.session_expiry_seconds` | int | `3600` | 刷新令牌/会话有效期（秒） |
| `yggdrasil.security.max_texture_width` | int | `1024` | 材质最大宽度（px） |
| `yggdrasil.security.max_texture_height` | int | `1024` | 材质最大高度（px） |

### `yggdrasil.feature_flags` — 功能开关

详见 [feature-flags.md](./feature-flags.md)。

## 修改配置后

修改 `config.yaml` 后需**重启服务**生效（运行时未实现热加载）。
